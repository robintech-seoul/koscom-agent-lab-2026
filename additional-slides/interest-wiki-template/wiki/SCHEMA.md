# 위키 규칙 (SCHEMA)

과제 1(hw1)의 llm-wiki 규칙을 웹 출처에 맞게 바꾼 것이다. 원문은 `raw/`에, 정리한 내용은 `wiki/`에 둔다.

## 구조

- `wiki/index.md`: 모든 페이지 목록. 한 줄에 페이지 하나, `- [[페이지이름]] — 한 줄 요약 (최종 수정일)`
- `wiki/log.md`: 변경 기록. 뒤에 덧붙이기만 하고 앞의 내용은 고치지 않는다.
- `wiki/pages/<페이지이름>.md`: 페이지 이름은 영문 소문자와 하이픈 (예: `us-genius-act`)
- `wiki/pages/overview.md`: 주제 전체 요약과 주요 일정 표. 항상 있어야 한다.

## 페이지 형식

```markdown
---
title: 미국 GENIUS Act
updated: 2026-10-28
sources: 3
---

# 미국 GENIUS Act

## 요약
3~5줄.

## 주요 내용
- 사실 문장 [출처: raw/2026-10-28/genius-act-rule.md]

## 일정
| 날짜 | 내용 | 출처 |

## 관련 페이지
- [[overview]], [[eu-mica]]

## 변경 이력
- 2026-10-28: 시행규칙 초안 내용 추가
```

## 출처 표기

- 모든 사실 문장 끝에 `[출처: raw/<날짜>/<파일>.md]`를 단다. URL은 raw 파일에 있으므로 위키에는 raw 경로만 쓴다.
- 출처가 둘 이상이면 `[출처: raw/a.md, raw/b.md]`.
- 의견이나 전망은 누구의 의견인지 문장 안에 쓴다. 예: "○○법무법인은 ~로 본다 [출처: ...]"

## 바뀐 정보

- 현재 유효한 내용만 "주요 내용"에 둔다.
- 바뀌기 전 내용은 "변경 이력"으로 옮기고 언제, 무엇이 바뀌었는지 적는다.
- 출처끼리 내용이 다르면 둘 다 적고 `> 확인 필요:` 줄을 단다.
