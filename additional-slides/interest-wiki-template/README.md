# 추가 실습 1 — 관심 주제 위키 만들기 (Claude 데스크톱 앱, Cowork)

관심 있는 주제를 정해 두면 Claude가 웹에서 정보를 모으고(수집), 위키에 정리하고(ingest), 위키를 점검(lint)합니다. 코드는 쓰지 않고, 이 폴더의 마크다운 파일로 역할과 절차를 정합니다. 실행할 때마다 `journal/`에 기록을 남기기 때문에, 다음 실행은 지난번 이후의 정보만 찾습니다.

## 준비

- Claude 데스크톱 앱 (Pro 이상 요금제, Cowork 사용 가능)
- 이 폴더(`interest-wiki-template`)를 원하는 위치에 복사하고 이름을 바꿉니다. 예: `C:\work\my-interest-wiki`

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `CLAUDE.md` | 전체 절차. "리서치 돌려줘"라고 하면 무엇을 하는지 적혀 있습니다 |
| `interest.md` | 내 관심 주제와 키워드. **이 파일만 고치면 됩니다** |
| `roles/scout.md` | 수집 담당 지시문 |
| `roles/ingest.md` | 위키 반영 담당 지시문 |
| `roles/lint.md` | 위키 점검 담당 지시문 |
| `wiki/SCHEMA.md` | 위키 작성 규칙 (과제 1 규칙을 웹 출처용으로 바꾼 것) |
| `raw/` | 수집한 원문 요약 (날짜별) |
| `journal/` | 실행 기록, 수집한 URL 목록, 점검 결과 |

## 실습

### ① 폴더 연결 (5분)

1. 데스크톱 앱에서 Cowork로 전환합니다.
2. 새 작업을 열고 작업 폴더로 복사한 폴더를 선택합니다. 폴더 접근을 허용합니다.
3. 아래처럼 물어 CLAUDE.md를 읽었는지 확인합니다.

```text
이 폴더의 CLAUDE.md를 읽고, "리서치 돌려줘"라고 하면 무엇을 하는지 순서대로 설명해줘.
```

### ② 관심 주제 정하기 (10분)

`interest.md`를 직접 고쳐도 되고, Claude에게 맡겨도 됩니다.

```text
interest.md를 내 관심 주제로 바꿔줘.
주제: (예: 국내 ETF 신상품과 상장 동향)
알고 싶은 것: (2~3가지)
키워드 묶음은 3개로 나누고, 제외할 것과 선호하는 출처도 채워줘.
```

키워드 묶음 하나를 scout 하나가 맡습니다. 묶음이 겹치지 않게 나누는 것이 좋습니다.

### ③ 첫 실행 (20분)

```text
리서치 돌려줘.
```

Claude가 하는 일을 지켜봅니다.

- 키워드 묶음마다 서브에이전트(scout)를 띄워 병렬로 검색하는지
- `raw/<오늘 날짜>/`에 출처별 파일이 생기는지
- ingest가 `wiki/pages/`, `wiki/index.md`, `wiki/log.md`를 고치는지
- lint 결과가 `journal/lint-<날짜>.md`에 남는지
- 마지막에 `journal/runs.md`에 실행 기록이 붙는지

끝나면 아래를 확인합니다.

| 확인할 것 | 볼 파일 |
|---|---|
| 새 출처 몇 건, 건너뛴 것 몇 건 | `journal/runs.md` |
| 만들어진 페이지 | `wiki/index.md` |
| 위키 문장마다 출처가 달렸는지 | `wiki/pages/*.md` |
| 사람이 확인해야 할 항목 | `journal/lint-<날짜>.md` |

### ④ 두 번째 실행 (10분)

같은 요청을 한 번 더 합니다.

```text
리서치 돌려줘.
```

이번에는 `journal/seen.md`에 있는 URL을 건너뛰고, `runs.md`의 마지막 실행 이후 정보를 찾아야 합니다. 새로 수집한 건수가 첫 실행보다 적은지, `runs.md`에 두 번째 기록이 붙었는지 확인합니다.

### ⑤ 위키로 질문하기 (5분)

```text
위키만 보고 답해줘. (질문)
답의 문장마다 근거가 된 위키 페이지와 raw 파일 경로를 적어줘.
위키에 없는 내용이면 없다고 말해줘.
```

### ⑥ 예약 실행 (10분)

Cowork 작업 창에서 `/schedule`을 입력하거나, 왼쪽 사이드바의 Scheduled에서 새 예약 작업을 만듭니다.

- 지시: `리서치 돌려줘.`
- 작업 폴더: 이 폴더
- 주기: 매일 오전 8시 (원하는 주기로)

예약 작업은 실행할 때마다 새 세션으로 시작합니다. 그래서 지난 실행을 기억하려면 `journal/runs.md` 같은 파일 기록이 필요합니다. 로컬 폴더를 읽고 쓰려면 실행 시점에 데스크톱 앱이 열려 있어야 합니다.

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| CLAUDE.md 내용을 따르지 않음 | 요청 앞에 "CLAUDE.md를 읽고"를 붙입니다 |
| scout를 병렬로 띄우지 않고 혼자 검색함 | "키워드 묶음마다 서브에이전트를 따로 띄워서"라고 덧붙입니다 |
| 수집이 너무 많아 오래 걸림 | `CLAUDE.md`의 최대 건수(15건)와 `roles/scout.md`의 묶음당 건수(5건)를 줄입니다 |
| 위키 문장에 출처가 없음 | "wiki를 lint해줘"로 lint만 다시 돌립니다 |
