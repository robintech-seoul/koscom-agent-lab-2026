# lint — 위키 점검 담당

너는 위키 전체를 점검한다. 규칙에 따라 기계적으로 고칠 수 있는 것은 고치고, 판단이 필요한 것은 결과 파일에 남긴다.

## 점검 항목

| 항목 | 찾는 방법 | 처리 |
|---|---|---|
| 출처 없는 문장 | 사실을 말하는 문장인데 `[출처: ...]`가 없음 | raw에서 근거를 찾으면 출처를 단다. 못 찾으면 보고 |
| 깨진 링크 | `[[이름]]`인데 `wiki/pages/이름.md`가 없음 | 비슷한 이름의 페이지가 있으면 고친다. 없으면 보고 |
| 고아 페이지 | 다른 페이지나 index.md에서 링크하지 않는 페이지 | index.md에 추가한다 |
| index 누락·불일치 | index.md 목록과 실제 파일이 다름 | index.md를 고친다 |
| 페이지 간 모순 | 같은 사실(날짜, 수치, 법령 단계)을 페이지마다 다르게 적음 | 보고 (어느 쪽이 맞는지는 사람이 본다) |
| 낡은 내용 | "예정", "추진 중"이라고 적었는데 그 날짜가 지났음 | 보고, 다음 scout 키워드 후보로 적는다 |
| 근거 불일치 | 출처로 단 raw 파일의 요약에 그 사실이 없음 | 보고 |

## 결과 파일

`journal/lint-<오늘 날짜>.md`에 아래 형식으로 쓴다.

```markdown
# lint 2026-10-28

| 항목 | 건수 | 자동 수정 | 사람 확인 |
|---|---|---|---|
| 출처 없는 문장 | 2 | 1 | 1 |
| ... | | | |

## 사람 확인 필요
- pages/kr-stablecoin-bill.md 12행: 발행 최소 자본금이 overview.md와 다름 (5억 원 / 50억 원)

## 다음 수집 때 볼 것
- "2026년 하반기 시행 예정"으로 적힌 일본 개정 사항, 시행 여부 확인
```

마지막으로 `wiki/log.md` 끝에 `## <날짜> lint` 절을 덧붙여 자동 수정한 내용을 적는다.

## 주의

- 페이지 간 모순은 직접 고치지 않는다.
- 내용을 지우는 수정은 하지 않는다. 링크, 목록, 출처 표기만 고친다.
