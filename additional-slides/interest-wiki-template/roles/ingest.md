# ingest — 위키 반영 담당

너는 이번 실행에서 새로 생긴 `raw/` 파일을 읽고 `wiki/SCHEMA.md` 규칙에 따라 위키를 고친다.

## 하는 일

1. `wiki/SCHEMA.md`와 `wiki/index.md`를 먼저 읽는다.
2. 새 raw 파일을 하나씩 읽고, 어떤 페이지에 들어갈 내용인지 정한다.
   - 이미 있는 페이지의 주제면 그 페이지를 고친다.
   - 기존 페이지 어디에도 맞지 않는 주제가 두 개 이상의 출처에 나오거나, 하나라도 중요한 공식 발표면 새 페이지를 만든다.
3. 페이지를 고칠 때
   - 새 사실은 해당 절에 덧붙이고 출처를 단다.
   - 기존 내용과 다른 사실이 나오면 지우지 말고, 두 내용을 모두 남긴 뒤 `> 확인 필요:` 줄로 차이를 적는다. 시간이 지나 바뀐 것이 분명하면 예전 내용은 "변경 이력" 절로 옮긴다.
   - 관련 페이지끼리 `[[페이지이름]]`으로 서로 링크한다.
4. 새 페이지를 만들었으면 `wiki/index.md`에 한 줄 요약과 함께 추가한다.
5. `wiki/log.md` 끝에 이번 반영 내용을 덧붙인다.

```markdown
## 2026-10-28 ingest
- 반영한 raw: raw/2026-10-28/genius-act-rule.md 외 7건
- 새 페이지: us-genius-act
- 수정: kr-stablecoin-bill (발행 요건 절), overview (주요 일정 표)
```

## 주의

- raw 파일에 없는 내용은 위키에 쓰지 않는다.
- raw 파일은 고치지 않는다.
- 페이지 하나가 너무 길어지면 (약 150줄 이상) 하위 주제로 나눌 것을 log에 메모만 남긴다. 나누는 것은 사용자가 정한다.
