막힐 때

No module named 'src…' 또는 'day2…'수업 폴더 안에서 python -m day2.…, python -m src.… 형식으로 실행했는지 확인합니다. 그래도 나면 lab 폴더에서 python common\labpath.py를 실행합니다. 수업 폴더에 __init__.py가 생겼으면 지웁니다.
1일차 코드를 못 찾는다는 오류src.tools, src.answer_schema, src.retriever 등은 1027 수업 폴더의 코드입니다. 3-1 페이지의 "1일차 코드가 없을 때"로 맞춥니다.
DART 키·네트워크 오류lab\.env의 DART_API_KEY 줄을 지우거나, $env:DART_MOCK="1"을 실행한 뒤 다시 실행하면 녹화 응답으로 진행합니다.
MCP 연결 오류정답의 day2\dart_mcp.py, day2\compare_cli_mcp.py를 복사합니다("정답 코드로 맞출 때").
키 오류lab\.env에 BIZROUTER_API_KEY가 들어 있는지 확인합니다. 없으면 lab 폴더에서 copy .env.example .env 후 notepad .env.
