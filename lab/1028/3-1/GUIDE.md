## 이번 시간에 하는 것

같은 DART(전자공시) 조회 기능을 두 가지 방식으로 만들어 에이전트에 연결합니다. 하나는 셸에서 실행하는 CLI 스크립트이고, 다른 하나는 MCP 서버입니다. 같은 질문 10건으로 두 방식을 비교해, 언제 무엇을 쓸지 수치로 판단합니다.

- 질문에 나오는 "A사", "B사"는 강사가 정해 줍니다.

## 실습

### 실습 ① 같은 기능을 두 방식으로 만들기 (교재 97쪽)

두 방식의 기능은 같게 하고 연결 방식만 다르게 만들어야 비교할 수 있습니다.

```text
day2/dart_cli.py를 만들어줘. argparse 서브커맨드 search(corp, days), document(rcept_no).
OpenDART API 호출, 결과는 JSON으로 stdout 출력. 키는 환경 변수.
```

```text
같은 기능을 day2/dart_mcp.py로 FastMCP 서버(stdio)로 만들어줘.
도구 설명문과 입력 스키마를 명확히 작성.
```

FastMCP는 Python 함수에 데코레이터를 붙여 MCP 서버를 만드는 라이브러리입니다. MCP 서버는 도구 설명문과 입력 스키마를 얼마나 명확히 썼느냐에 따라 호출 정확도가 달라집니다.

### 실습 ② 두 에이전트를 질문 10건으로 비교 (교재 98쪽)

```text
LangGraph 에이전트 2개를 만들어줘.
A: 셸 실행 도구 하나로 dart_cli.py를 호출 (사용법은 시스템 프롬프트에)
B: langchain-mcp-adapters로 dart_mcp.py 연결
DART 단독 질문 10건을 둘 다 실행하고
도구 정의 토큰, 맞는 호출 비율, 인자 오류 수, 지연을 표로 출력해줘.
```

질문 예: "A사 최근 1개월 주요 공시 요약". 표가 나온 뒤 강사가 `dart_mcp.py`를 코드 수정 없이 Claude Desktop에 연결하는 시연을 합니다(재사용성).
