막힐 때

No module named 'src…' 또는 'day2…'수업 폴더 안에서 python -m day2.…, python -m src.… 형식으로 실행했는지 확인합니다. 그래도 나면 lab 폴더에서 python common\labpath.py를 실행합니다. 수업 폴더에 __init__.py가 생겼으면 지웁니다.
앞 수업 코드를 못 찾는다는 오류위의 "방법 A"를 실행합니다. 방법 B로 하는 중이면 방법 B 맨 위의 "앞 수업 맞추기"를 실행합니다.
run_eval이 멈춘 것처럼 진행이 없음--workers를 2 이상으로 주지 않았는지 확인합니다. 2일차 멀티 에이전트는 --workers 1(기본값)로 한 질문씩 실행합니다. 결합 질문 10건은 질문당 30~40초라 5~7분 걸립니다.
update_index가 0건을 추가함이미 반영된 상태입니다. 같은 조항은 다시 넣지 않습니다.
위키 ingest 시간 초과2단계는 건너뛰고 3단계(미리 갱신한 위키)로 비교합니다.
키 오류lab\.env에 BIZROUTER_API_KEY가 들어 있는지 확인합니다. 없으면 lab 폴더에서 copy .env.example .env 후 notepad .env.
429 오류여러 명이 동시에 호출해 한도에 걸린 것입니다. 코드가 기다렸다 자동으로 다시 시도합니다.

명령의 기준은 이 폴더의 GUIDE.md와 solutions\1028\4-3\results\의 실행 기록(각 .log 첫 줄)입니다.
