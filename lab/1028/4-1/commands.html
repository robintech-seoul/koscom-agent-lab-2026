키 필요 없음

claude
Claude Code에 입력
eval/results/의 모든 결과 jsonl을 읽어 구조별 표를 만들어줘:
질문당 입력/출력 토큰, 비용(CLAUDE.md의 단가), p50/p95 지연, 점수.
대상: 기준선, RAG, 에이전틱, 위키, 단일, 멀티.
PowerShell
python -m src.cost_table --daily 1000
  • 결과 파일만 읽습니다. LLM을 부르지 않습니다.
  • --daily는 하루 질문 수입니다. 바꿔 가며 하루 비용을 봅니다.
  • 파일 이름 앞부분(baseline, rag, agentic, wiki, single, multi)으로 구조를 나눕니다. rag_cite, multi_seq, multi_q30처럼 이름이 다른 결과는 표에 들어가지 않습니다.
  • 기준선은 Claude Code 헤드리스 결과의 비용 필드(구독 계정이라 실제 청구는 없음)를 씁니다.

막힐 때

No module named 'src…' 또는 'day2…'수업 폴더 안에서 python -m day2.…, python -m src.… 형식으로 실행했는지 확인합니다. 그래도 나면 lab 폴더에서 python common\labpath.py를 실행합니다. 수업 폴더에 __init__.py가 생겼으면 지웁니다.
1일차 코드를 못 찾는다는 오류src.tools, src.answer_schema, src.retriever 등은 1027 수업 폴더의 코드입니다. 3-1 페이지의 "1일차 코드가 없을 때"로 맞춥니다.
표에 구조가 빠짐lab\eval\results\에 그 구조의 결과 파일이 있는지 확인합니다. 없으면 "앞 수업 결과 파일이 없을 때"로 복사합니다.
Phoenix 실행 오류실습 ②는 생략합니다. 실습 ①만으로 확인 기준을 채웁니다.

명령의 기준은 이 폴더의 GUIDE.md와 solutions\1028\4-1\results\의 실행 기록(각 .log 첫 줄)입니다.
