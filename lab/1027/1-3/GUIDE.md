## 실습

### 실습 ① 검색 모듈을 만든다 (교재 40쪽)

네 가지 검색 방식과 메타데이터 필터를 함수 하나로 묶습니다. 이후 모든 그래프가 이 검색기를 같이 씁니다.

```text
src/retriever.py를 만들어줘.
- BM25 두 종류(공백 토큰, Kiwi 형태소), 벡터(로컬 임베딩 모델 + Chroma)
- RRF로 결합, 선택적으로 리랭커 적용
- hybrid_search(query, k=5, filters=None, mode="hybrid|bm25|bm25_kiwi|vector")
- filters는 security_level, effective_date 메타데이터 필터를 지원
```

- `filters`는 4-2(보안 등급)와 4-3(시행일)에서 다시 씁니다.

### 실습 ② 검색 방식별 적중 수를 비교한다 (교재 41쪽)

답을 만들지 않고 검색만 따로 재면, 어느 방식이 정답 조항을 찾아오는지 바로 비교할 수 있습니다.

```text
평가셋 30건에 대해 mode별 상위 5건 안에 gold_citations 조항이
들어간 질문 수를 표로 출력하는 스크립트를 만들어줘.
리랭커 적용 전후도 포함해.
```

표가 나오면 BM25와 벡터의 승패가 갈리는 문항을 찾습니다.
- 표현 변형 문항(질문과 원문의 단어가 다른 문항)에서 1개
- 고유 토큰 문항(코드, 숫자 같은 고유한 단어가 있는 문항)에서 1개

### 실습 ③ 검색 후 답을 만드는 그래프 (교재 42쪽)

검색 노드와 답변 생성 노드 두 개로 된 그래프가 첫 번째 RAG 방식입니다.

```text
src/graphs/graph_rag.py를 만들어줘. LangGraph StateGraph로
retrieve 노드(hybrid_search) → generate 노드. CLAUDE.md의 1.x API 예시를 따를 것.
```

```
START → retrieve (hybrid_search) → generate → END
```

그래프를 만든 뒤 `run_eval.py`로 평가셋 30건을 실행하고 결과 파일을 확인합니다.
