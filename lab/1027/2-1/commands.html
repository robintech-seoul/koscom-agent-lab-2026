RAG 결과 채점 · 실습 ①

BizRouter 키 필요
PowerShell
python -m src.run_eval --results eval/results/rag_r1.jsonl --score
python -m src.run_eval --results eval/results/rag_r2.jsonl --score
  • --score를 붙이면 규칙 채점에 더해 RAGAS 채점을 합니다. 채점 모델(LLM)을 부르므로 키가 필요합니다.
기록된 출력 (rag_r1)
{"name": "rag_r1", ... "citation_hit": 0.87, "faithfulness": 0.877, "context_recall": 0.831, ...}

기준선 결과 채점

BizRouter 키 필요
PowerShell
python -m src.run_eval --results eval/results/baseline_r1.jsonl --score --baseline
python -m src.run_eval --results eval/results/baseline_r2.jsonl --score --baseline
  • --baseline은 기준선의 문맥을 data\regs_all.md 전체로 놓고 채점하라는 뜻입니다.
  • 기준선의 context_recall 1.0은 전체를 넣었기 때문이고 성능이 좋다는 뜻이 아닙니다. 기준선은 faithfulness, 비용, 함정 문항으로 비교합니다.
기록된 출력 (baseline_r1)
{"name": "baseline_r1", ... "faithfulness": 0.794, "context_recall": 1.0, "stale": 1, "leaked": 3, ...}
