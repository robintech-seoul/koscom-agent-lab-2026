규칙 파일과 문서 반영 · 실습 ①

Claude 구독 계정
PowerShell
claude
Claude Code에 입력
wiki/SCHEMA.md를 만들어줘. Karpathy llm-wiki 패턴을 따르되 다음을 규칙으로:
- wiki/pages/의 모든 문장 끝에 원문 근거 [doc §article, 시행일] 링크 필수
- 개정된 조항은 현행만 본문에, 개정 전은 "이력" 절로
- 보안 등급이 다른 내용은 한 페이지에 섞지 않음
- index.md(전체 목록), log.md(append-only) 유지
  • 위키는 모든 수업이 함께 쓰므로 저장소 루트의 wiki\에 만듭니다(lab\wiki\SCHEMA.md).
Claude Code에 입력
wiki/SCHEMA.md 규칙에 따라 data/raw/의 (강사가 지정한 문서 3~5개)를 ingest해서 wiki를 갱신해줘.
  • 문서 3~5개만 직접 반영합니다. 나머지는 미리 만든 위키(data\wiki\)로 채웁니다.

막힐 때

No module named 'src…'수업 폴더 안에서 python -m src.… 형식으로 실행했는지 확인합니다. 그래도 나면 lab 폴더에서 python common\scripts\check_env.py를 다시 실행합니다. .venv를 새로 만들었다면 꼭 다시 실행해야 합니다.
ingest 시간 초과미리 만든 위키(data\wiki\)를 씁니다. 루트에 wiki\index.md가 없으면 그래프가 자동으로 씁니다.
점수표에 방식이 빠짐eval\results\에 그 방식의 결과 파일이 있는지 확인합니다.
