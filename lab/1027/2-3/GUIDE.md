## 실습

### 실습 ① 원문 폴더를 직접 탐색하기 (교재 70쪽, 15분)

색인 없이 원문 폴더만 주고 질문합니다. 에이전트가 grep으로 찾고, 파일을 열고, 교차 참조를 따라가는 경로를 관찰합니다. 질문은 강사가 지정하는 교차 참조 문항 1개입니다.

```text
data/raw/ 폴더만 사용해서 답해줘. 색인이나 data/parsed는 쓰지 마.
질문: (교차 참조 문항 1개)
어떤 파일을 왜 열었는지 단계별로 보여줘.
```

탐색 경로를 기록해 두면, 실습 ③에서 만든 그래프의 도구 호출 로그와 비교할 수 있습니다.

### 실습 ② (선택) 직접 탐색 방식 일괄 실행 (교재 71쪽)

시간이 남을 때만 합니다. 이 점수는 참고용이고 4방식 점수표에는 넣지 않습니다.

```text
scripts/run_claude_explore.sh를 run_claude_baseline.sh처럼 만들어줘.
허용 도구는 Read, Grep, Glob. 대상은 data/raw/. 결과는 explore_r1.jsonl.
```

### 실습 ③ 도구를 반복 호출하는 그래프 만들기 (교재 72쪽)

에이전트가 세 도구 중 하나를 골라 호출하고, 결과를 보고 다시 고르는 그래프를 만듭니다. 비용이 끝없이 늘지 않도록 최대 반복 횟수를 정합니다.

```text
src/graphs/graph_agentic.py를 만들어줘.
- 도구: grep(pattern, path), read_file(path), hybrid_search(query, k, filters)
- LangGraph ToolNode + 조건부 엣지 루프, 최대 반복 8회
- 최종 답은 answer_schema 구조화 출력
- 도구 호출 로그(도구명, 인자, 결과 길이)를 state에 누적
```

```
START → agent ─ 도구 호출 있음 → tools (ToolNode) ─ 결과 반환 (최대 8회) → agent
              └ 도구 호출 없음 → answer (answer_schema) → END
```

ToolNode는 LLM이 요청한 도구를 실제로 실행해 주는 LangGraph 노드입니다. 그래프를 만든 뒤 `run_eval.py`로 평가셋 30건을 실행하고 RAG와 점수, 지연, 토큰을 비교합니다.
