1

조항 단위 적재 · 실습 ①

키 필요 없음
PowerShell
python -m src.ingest
  • 루트의 data\raw\ 아래 PDF 10, DOCX 7, HWPX 3개를 읽습니다. 옆의 .txt 사본은 건너뜁니다.
  • 결과는 루트의 data\parsed\articles.jsonl에 저장됩니다.
  • python src\ingest.py가 아니라 python -m src.ingest 형식으로 실행해야 common의 config.py를 찾습니다.
  • 조항 3건 이상을 articles.jsonl과 원문(.txt 사본)에서 직접 대조합니다.
정상 출력
문서 20개, 조항 272개 → data/parsed/articles.jsonl 파싱 실패 문서: 0건 메타데이터 누락: 0건
2

평가셋 5건 원문 대조 · 실습 ②

키 필요 없음
PowerShell
notepad C:\koscom-agent-lab-2026\lab\eval\questions.jsonl
  • 5건을 골라 gold_citations(문서, 조항, 시행일)가 원문과 같은지, gold_answer가 그 조항 내용과 맞는지 봅니다.
  • 평가셋은 수정하지 않습니다.
3

러너로 기준선 결과 채점 · 실습 ③

키 필요 없음
PowerShell
python -m src.run_eval --results eval/results/baseline_r1.jsonl
  • 1-1 결과 파일을 읽어 규칙으로 채점합니다(인용 적중, 개정 전 판 인용, 권한 밖 노출). LLM을 부르지 않습니다.
  • 요약은 루트의 eval\results\scores.csv에도 덧붙습니다.
  • baseline_r1.jsonl이 없으면 먼저 복사합니다: copy C:\koscom-agent-lab-2026\solutions\1027\1-1\results\baseline_r1.jsonl C:\koscom-agent-lab-2026\lab\eval\results\
  • 이 단계에서 키를 요구하면 만든 run_eval.py가 잘못된 것입니다.
정상 출력
{"name": "baseline_r1", "n": 30, "citation_hit": 1.0, ... "stale": 1, "leaked": 3, ...}
+

러너로 샘플 그래프 실행

BizRouter 키 필요 · 선택
PowerShell
python -m src.run_eval --graph src.graphs.sample_graph --name sample --limit 3
  • 샘플 그래프(common\src\graphs\sample_graph.py)는 --graph 기능을 시험하려고 둔 연습용 그래프입니다. 질문을 LLM에 그대로 보낼 뿐 검색을 하지 않아 점수는 의미가 없습니다.
  • 진짜 그래프는 1-3에서 만듭니다. 시간이 없으면 건너뜁니다.
  • citation_hit 0.0, no_citation 3은 정상입니다. 답이 비어 있을 수 있습니다. 결과 파일에 토큰과 지연 시간이 기록되면 됩니다.
정상 출력
3건 → eval/results/sample_r1.jsonl (오류 0건)

막힐 때

No module named 'src…'수업 폴더 안에서 python -m src.… 형식으로 실행했는지 확인합니다. 그래도 나면 lab 폴더에서 python common\scripts\check_env.py를 다시 실행합니다. .venv를 새로 만들었다면 꼭 다시 실행해야 합니다.
HWPX 파싱 실패위의 "정답 코드로 맞출 때"로 ingest.py를 복사해 실행합니다.
--graph 또는 --results 중 하나가 필요하다run_eval은 옵션 없이 실행하지 않습니다. 3단계 명령처럼 --results나 --graph를 붙입니다.
키 오류lab\.env에 BIZROUTER_API_KEY가 들어 있는지 확인합니다. 없으면 lab 폴더에서 copy .env.example .env 후 notepad .env.

명령의 기준은 이 폴더의 GUIDE.md와 solutions\1027\1-2\results\의 실행 기록(각 .log 첫 줄)입니다.
