질문 1건 확인 · 실습 ①

Claude 구독 계정
Claude Code에 입력
data/regs_all.md 전체를 읽고, 그 내용만 근거로 다음 질문에 답해줘.
다른 파일은 열지 마. 답에는 문서명·조항·시행일을 인용해.
질문: 시세 전송 지연 시 참가사 통보 기준은?
  • 답에 문서명, 조항, 시행일이 붙었는지 봅니다.
  • data/regs_all.md 말고 다른 파일을 열지 않았는지 봅니다.
  • 수업 폴더에서 열어도 루트의 data/regs_all.md를 찾아 읽습니다.

30건 실행 스크립트 만들기 · 실습 ②

Claude 구독 계정
Claude Code에 입력
scripts/run_claude_baseline.sh 를 만들어줘.
- eval/questions.jsonl의 각 질문에 대해 claude -p를 호출
- 도구는 Read만 허용, 읽을 파일은 data/regs_all.md 하나
- --output-format json 결과에서 답변·토큰·비용을 추출해
  eval/results/baseline_r1.jsonl 형식(CLAUDE.md 참고)으로 저장
- --model은 CLAUDE.md의 고정 모델 사용
실행 전에 검수
  • --allowedTools가 Read 하나인가
  • --model이 claude-haiku-5-5인가
  • ANTHROPIC_API_KEY를 쓰지 않는가

30건 실행

Claude 구독 계정
Git Bash
cd /c/koscom-agent-lab-2026/lab/1027/1-1
source ../../.venv/Scripts/activate
bash scripts/run_claude_baseline.sh 1
  • .sh는 Git Bash에서 실행합니다. 시작 메뉴에서 Git Bash를 엽니다.

  • 2회차(bash scripts/run_claude_baseline.sh 2)는 2-1에서 편차를 볼 때 쓰므로, 다음 시간 중에 돌려 둡니다.
정상 출력
baseline 1회차: 30건, 동시 4개 1/30 완료 ... 30건 → eval/results/baseline_r1.jsonl (오류 0건)

막힐 때

API 요금으로 실행됨ANTHROPIC_API_KEY, ANTHROPIC_BASE_URL 환경 변수를 지우고 claude에서 구독 계정으로 로그인합니다.

명령의 기준은 이 폴더의 GUIDE.md와 solutions\1027\1-1\results\의 실행 기록(각 .log 첫 줄)입니다.
