외부API이용지침
문서번호: HB-DEV-001
보안등급: 일반
시행일: 2025-02-01
개정차수: 1
제1조(목적)
이 지침은 한빛시장정보(주)(이하 "회사"라 한다)가 제공하는 외부 API를 참가사 등 외부 기관이 이용할 때 지켜야 할 사항을 정하여, 서비스의 안정적인 운영과 정보의 안전한 이용을 확보하는 것을 목적으로 한다.
제2조(정의)
이 지침에서 사용하는 용어의 뜻은 다음과 같다.
1. "외부 API"란 회사가 외부 기관에 시세와 종목 정보를 제공하기 위해 공개한 응용 프로그램 인터페이스를 말한다.
2. "이용 기관"이란 회사의 승인을 받아 외부 API를 이용하는 참가사 등의 기관을 말한다.
3. "API 키"란 이용 기관을 식별하고 인증하기 위하여 회사가 발급하는 문자열을 말한다.
4. "호출"이란 이용 기관이 외부 API에 정보를 요청하는 1회의 요청을 말한다.
5. "담당 개발자"란 외부 API의 운영과 이용 기관 지원을 맡은 개발팀 소속 직원을 말한다.
6. "시험 환경"이란 이용 기관이 외부 API의 동작을 확인하기 위하여 운영 환경과 분리하여 제공하는 환경을 말한다.
제3조(이용 신청과 승인)
① 외부 API를 이용하려는 기관은 회사가 정한 신청서를 개발팀에 제출한다.
② 개발팀은 신청서를 접수한 날부터 5영업일 이내에 심사하여 승인 여부를 통보한다.
③ 승인된 이용 기관에는 시험 환경용 API 키를 먼저 발급하고, 시험을 마친 후 운영 환경용 API 키를 발급한다.
④ 신청서에는 기관명, 담당자 연락처, 이용 목적, 이용할 API의 범위, 예상 호출량을 적는다. 기재 내용이 부족하면 개발팀은 보완을 요청할 수 있으며, 보완에 걸린 기간은 제2항의 심사 기간에 넣지 않는다.
⑤ 개발팀은 승인 사실과 발급한 API 키의 종류를 이용 기관 담당자에게만 통보한다.
제4조(이용 범위)
① 이용 기관은 승인받은 범위의 API만 이용할 수 있다.
② 이용 기관은 외부 API로 받은 정보를 제3자에게 재판매하거나 무단으로 제공하여서는 아니 된다.
③ 회사는 이용 범위를 넘는 호출이 확인되면 해당 호출을 제한할 수 있다.
④ 이용 기관은 외부 API로 받은 정보를 화면에 표시하거나 가공하여 제공할 때 정보의 출처가 회사임을 밝혀야 한다.
⑤ 이용 기관이 이용 범위를 넓히려는 경우에는 제3조의 절차에 따라 변경 신청을 한다.
제5조(시험 환경 이용)
① 시험 환경은 운영 환경과 별도로 운영하며, 시험 환경에서 제공하는 시세는 실제 시세가 아닌 모의 데이터이다.
② 시험 환경의 호출은 이용 기관당 하루 10,000회를 넘을 수 없다.
③ 이용 기관은 시험 환경에서 정상 동작을 확인한 후에 운영 환경 이용을 신청한다.
④ 시험 환경에서 발급한 API 키는 운영 환경에서 사용할 수 없으며, 시험 환경의 호출 기록은 30일간 보관한다.
⑤ 시험 환경은 개발팀이 필요하다고 판단하는 경우 사전 안내 후 초기화할 수 있다.
제6조(호출 한도)
① 외부 기관이 회사의 시세 조회 API를 호출하는 횟수는 기관당 분당 600회로 한다.
② 호출 횟수는 기관별 인증 정보를 기준으로 집계한다.
제7조(이용 시간과 점검)
① 외부 API는 24시간 이용할 수 있다. 다만 정기 점검 시간에는 이용이 제한될 수 있다.
② 회사는 정기 점검을 하려는 경우 점검 예정일 3영업일 전까지 이용 기관에 알린다.
③ 긴급 점검이 필요한 경우에는 점검을 시작하기 전에 가능한 범위에서 이용 기관에 알린다.
④ 회사는 정기 점검의 시간대를 가능한 한 이용이 적은 시간으로 정하고, 점검이 끝나면 이용 기관에 점검 종료 사실을 알린다.
⑤ 점검 시간이 예정보다 길어지는 경우에는 연장 사유와 새 종료 예정 시각을 이용 기관에 알린다.
제8조(호출 기록)
① 회사는 외부 API 호출에 대하여 호출 시각, 이용 기관, 호출 대상, 응답 결과를 기록한다.
② 호출 기록은 6개월간 보관한다.
③ 이용 기관이 호출 기록의 확인을 요청하면 개발팀은 해당 기관의 기록에 한하여 이를 제공할 수 있다.
④ 호출 기록은 장애 분석과 이용 한도 관리를 위한 목적으로만 이용하며, 다른 목적으로 사용하려면 개발팀장의 승인을 받는다.
⑤ 호출 기록에는 응답 내용 자체를 저장하지 않고, 응답의 성공 여부와 응답에 걸린 시간만 기록한다.
제9조(API 키 관리)
① API 키 관리는 「정보보호규정」 제14조에 따른다.
② API 키의 유효기간은 1년으로 한다.
③ 개발팀은 유효기간 만료 14일 전에 이용 기관에 갱신 절차를 안내한다.
④ 이용 기관은 API 키가 노출되었거나 노출이 의심되면 즉시 개발팀에 알려야 하며, 개발팀은 해당 키를 폐기하고 새 키를 발급한다.
⑤ 이용 기관은 API 키를 소스코드나 공개된 저장소에 두어서는 아니 되며, 키를 사용하는 담당자를 개발팀에 등록하고 담당자가 바뀌면 7일 안에 변경 사항을 알린다.
⑥ 개발팀은 반기마다 발급된 API 키의 목록과 사용 현황을 점검하고, 장기간 사용되지 않는 키는 이용 기관에 확인한 후 폐기한다.
제10조(장애 시 협조)
① 이용 기관은 외부 API 이용 중 오류나 지연을 발견하면 개발팀에 지체 없이 알린다.
② 개발팀은 신고를 받으면 2영업일 이내에 원인과 조치 결과를 해당 기관에 회신한다.
③ 이용 기관은 자체 시스템의 장애가 외부 API 이용에 영향을 주는 경우 그 사실을 개발팀에 알려야 한다.
④ 개발팀은 장애 원인이 회사의 시스템에 있는 경우 이용 기관이 입은 영향을 확인하여 필요한 협조를 한다.
⑤ 개발팀은 같은 유형의 오류 신고가 반복되면 이용 안내 자료를 보완하여 이용 기관에 배포한다.
제11조(이용 제한과 종료)
① 회사는 이용 기관이 이 지침을 위반한 경우 이용을 제한하거나 승인을 취소할 수 있다.
② 이용을 제한하거나 승인을 취소할 때에는 사유를 기관에 서면으로 알린다.
③ 이용 기관이 이용을 종료하려는 경우 개발팀에 종료를 알리고, 개발팀은 해당 기관의 API 키를 즉시 폐기한다.
④ 이용 기관이 승인을 취소당한 경우 취소일부터 6개월이 지나기 전에는 새로 이용을 신청할 수 없다. 다만 개발팀장이 사정을 인정하는 경우에는 그러하지 아니하다.
⑤ 이용이 종료된 기관은 외부 API로 받아 보관 중인 정보 가운데 회사가 삭제를 요청한 정보를 지체 없이 삭제하여야 한다.
제12조(지침의 관리)
① 이 지침의 제정과 개정은 개발팀장이 주관한다.
② 개발팀장은 이 지침의 내용이 현재의 이용 환경에 맞는지 연 1회 점검한다.
③ 이 지침을 개정한 때에는 개정 내용을 이용 기관에 알린다.
④ 이 지침에서 정하지 아니한 사항은 개발팀장이 정하는 바에 따른다.
제13조(이용 안내와 문의)
① 개발팀은 외부 API의 이용 방법, 응답 형식, 오류 코드를 정리한 이용 안내서를 이용 기관에 제공한다.
② 이용 기관의 문의는 개발팀의 지원 창구로 접수하며, 개발팀은 접수한 날부터 2영업일 이내에 답변한다.
③ 이용 안내서를 개정한 경우에는 개정일과 변경 내용을 이용 기관에 알린다.
④ 개발팀은 자주 문의되는 사항을 모아 이용 기관이 볼 수 있도록 게시한다.
제14조(이용 기관의 의무)
① 이용 기관은 외부 API를 이용하는 시스템에서 호출 실패가 발생할 경우 짧은 간격으로 계속 재시도하지 않고, 일정한 간격을 두고 재시도하도록 구성하여야 한다.
② 이용 기관은 담당자의 연락처와 기관 정보가 바뀐 경우 변경일부터 7일 안에 개발팀에 알린다.
③ 이용 기관은 회사가 이 지침의 이행 여부를 확인하기 위하여 자료를 요청하면 5영업일 이내에 제출한다.
