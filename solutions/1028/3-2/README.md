# [3-2] 감독자 구성, 단일 에이전트와 비교

- **일시:** 2일차 10:00–11:00 (강의 15분 + 실습 35분)
- **교재:** 101–114쪽 (실습은 111–113쪽)
- **결과물:** `day2/agents.py`, 단일 vs 멀티 비교표

## 이번 시간에 하는 것

규정 담당과 공시 담당 에이전트를 감독자(supervisor) 아래에 두고, 최종 답을 검증자가 확인하는 멀티 에이전트를 만듭니다. 같은 도구를 모두 가진 단일 에이전트와 같은 질문으로 비교해, 멀티 에이전트가 이 과제에서 이득인지 수치로 판단합니다.

- 감독자: 질문을 받아 어느 에이전트에게 맡길지 정하고 결과를 모으는 에이전트
- 서브에이전트: 감독자에게 일을 받아 처리하고 결과(요약과 근거)를 돌려주는 에이전트
- 검증자: 최종 답의 인용을 원문으로 다시 확인하는 노드

## 준비

- 1일차 `graph_agentic.py`와 `graph_wiki.py` (1일차 점수가 좋았던 쪽을 규정 담당으로 씁니다)
- 3-1의 `day2/dart_mcp.py`
- 결합 질문 10건 (`eval/sets/`)

## 실습

### 실습 ① 감독자, 서브에이전트, 검증자 구성 (교재 111쪽)

```text
day2/agents.py를 만들어줘. LangGraph supervisor 구조:
- regulation_agent: 1일차 graph_agentic(또는 graph_wiki)을 서브그래프로
- disclosure_agent: 3-1의 MCP 도구 사용
- verifier: 최종 답의 citations를 read_source로 재확인, 시행일·보안등급 점검,
  실패 시 해당 서브에이전트로 되돌림(최대 1회)
- 서브에이전트는 요약과 evidence만 반환
```

### 실습 ② 단일 에이전트와 같은 10건으로 비교 (교재 112쪽)

1. 비교용 단일 에이전트를 만듭니다. regulation_agent와 disclosure_agent의 도구를 하나의 도구 묶음으로 가진 에이전트 1개입니다.
2. 결합 질문 10건을 둘 다 실행하고 정확도, 지연, 토큰을 표로 만듭니다.
