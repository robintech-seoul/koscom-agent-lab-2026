# 정보보호 계정, 인증, 비밀번호 관리

## 정보자산 분류
- 정보자산은 중요도에 따라 일반, 대외비, 비밀의 세 등급으로 분류한다 [정보보호규정 §제5조, 2026-04-01].
- 등급 표시가 없는 자산은 대외비로 취급한다 [정보보호규정 §제5조, 2026-04-01].

## 계정 관리
- 모든 이용자는 개인별로 부여된 계정을 사용하며 계정을 다른 사람과 공유하여서는 아니 된다 [정보보호규정 §제7조, 2026-04-01].
- 관리자 계정은 정보보호최고책임자의 승인을 받은 담당자에게만 발급한다 [정보보호규정 §제7조, 2026-04-01].
- 6개월 이상 사용하지 않은 계정은 정보보호 담당 부서가 이용자에게 알린 뒤 잠금 처리한다 [정보보호규정 §제7조, 2026-04-01].
- 로그인에 연속으로 3회 실패한 계정은 자동으로 잠기며 잠금 해제는 본인 확인 후 정보보호 담당 부서가 처리한다 [정보보호규정 §제7조, 2026-04-01].

## 사용자 인증과 비밀번호
- 외부에서 접속하는 경우에는 계정과 비밀번호에 더하여 추가 인증 수단을 함께 사용한다 [정보보호규정 §제8조, 2026-04-01].
- 비밀번호는 영문 대문자, 소문자, 숫자, 특수문자 중 세 가지 이상을 조합하여 10자리 이상으로 설정한다 [정보보호규정 §제8조, 2026-04-01].
- 초기 비밀번호는 최초 접속 시 즉시 변경하여야 한다 [정보보호규정 §제8조, 2026-04-01].
- 이용자는 비밀번호를 60일마다 변경하여야 한다 [정보보호규정 §제11조, 2026-04-01].
- 최근 5회 이내 사용한 비밀번호는 다시 사용할 수 없다 [정보보호규정 §제11조, 2026-04-01].
- 비밀번호 변경 기간이 지난 계정은 변경이 끝날 때까지 접속을 제한할 수 있다 [정보보호규정 §제11조, 2026-04-01].

## 접속 기록과 API 키
- 접속 기록은 변조되지 않도록 별도의 저장 공간에 보관하며 보관 기간은 1년이다 [정보보호규정 §제12조, 2026-04-01].
- API 키는 키 관리 시스템 KMS-2에 보관하며 소스코드 저장을 금지한다 [정보보호규정 §제14조, 2026-04-01].
- API 키가 노출되었거나 노출이 의심되는 경우에는 즉시 폐기하고 새 키를 발급한다 [정보보호규정 §제14조, 2026-04-01].

## 보안 사고 보고
- 이용자는 보안 사고를 발견하거나 의심되는 경우 즉시 소속 부서의 장과 정보보호 담당 부서에 알려야 한다 [정보보호규정 §제13조, 2026-04-01].
- 정보보호 담당 부서는 사고 접수 후 2시간 이내에 사고의 범위와 원인을 확인하여 정보보호최고책임자에게 보고한다 [정보보호규정 §제13조, 2026-04-01].

## 이력
- 2025-01-01 시행본에서는 비밀번호 변경 주기가 90일이었고 최근 사용 비밀번호 재사용 금지 규정은 없었다 [정보보호규정 §제11조, 2025-01-01].
- 2026-04-01 개정으로 변경 주기를 90일에서 60일로 단축하고 최근 5회 이내 사용한 비밀번호의 재사용을 금지하였다 [정보보호규정 §부칙, 2026-04-01].
