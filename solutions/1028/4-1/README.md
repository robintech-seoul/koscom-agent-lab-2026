## 이번 시간에 하는 것

이틀 동안 만든 6개 구조(기준선, RAG, 에이전틱, 위키, 단일, 멀티)의 질문당 비용, 지연 시간, 점수를 한 표로 정리합니다. 운영할 구조를 고를 때는 하루 비용과 p95 지연(100번 중 느린 쪽 5번을 뺀 최대 지연)을 함께 봅니다. 이 표는 과제 2 판정표에 그대로 들어갑니다.

## 준비

- `eval/results/`에 쌓인 6개 구조의 결과 파일
- CLAUDE.md에 고정 모델 단가가 들어 있는지 확인

## 실습

### 실습 ① 결과 파일을 모아 표를 만든다 (교재 131쪽)

```text
eval/results/의 모든 결과 jsonl을 읽어 구조별 표를 만들어줘:
질문당 입력/출력 토큰, 비용(CLAUDE.md의 단가), p50/p95 지연, 점수.
대상: 기준선, RAG, 에이전틱, 위키, 단일, 멀티.
```

- 기준선은 Claude Code 헤드리스 결과의 비용 필드를 씁니다.

### 실습 ② (선택) 호출 순서를 그림으로 본다 (교재 132쪽)

Phoenix는 에이전트가 어떤 순서로 무엇을 호출했는지 화면으로 보여 주는 오픈소스 도구입니다(사내 설치 가능). OpenInference는 LLM 호출과 도구 호출을 기록해 Phoenix로 보내는 계측 라이브러리입니다. 비용 측정에는 실습 ①의 표를 씁니다. 강사 시연으로 대신할 수 있습니다.

```text
Phoenix와 OpenInference 계측을 붙여서 agents.py 실행 경로가 Phoenix UI에 보이게 해줘.
```
