# 외부 API 이용

## 현행 기준
- 외부 API를 이용하려는 기관은 회사가 정한 신청서를 개발팀에 제출한다 [외부API이용지침 §제3조, 시행일 2026-02-01].
- 개발팀은 신청서를 접수한 날부터 5영업일 이내에 심사하여 승인 여부를 통보한다 [외부API이용지침 §제3조, 시행일 2026-02-01].
- 승인된 이용 기관에는 시험 환경용 API 키를 먼저 발급하고 시험을 마친 후 운영 환경용 API 키를 발급한다 [외부API이용지침 §제3조, 시행일 2026-02-01].
- 이용 기관은 승인받은 범위의 API만 이용할 수 있다 [외부API이용지침 §제4조, 시행일 2026-02-01].
- 이용 기관은 외부 API로 받은 정보를 제3자에게 재판매하거나 무단으로 제공하여서는 아니 된다 [외부API이용지침 §제4조, 시행일 2026-02-01].
- 시험 환경에서 제공하는 시세는 실제 시세가 아닌 모의 데이터이다 [외부API이용지침 §제5조, 시행일 2026-02-01].
- 시험 환경의 호출은 이용 기관당 하루 10,000회를 넘을 수 없다 [외부API이용지침 §제5조, 시행일 2026-02-01].
- 시세 조회 API의 호출 한도는 기관당 분당 300회이다 [외부API이용지침 §제6조, 시행일 2026-02-01].
- 호출 횟수는 기관별 인증 정보를 기준으로 집계한다 [외부API이용지침 §제6조, 시행일 2026-02-01].
- 한도를 초과한 기관에 대해서는 10분간 호출을 차단한다 [외부API이용지침 §제6조, 시행일 2026-02-01].
- 회사는 정기 점검을 하려는 경우 점검 예정일 3영업일 전까지 이용 기관에 알린다 [외부API이용지침 §제7조, 시행일 2026-02-01].
- 호출 기록은 6개월간 보관한다 [외부API이용지침 §제8조, 시행일 2026-02-01].
- 호출 기록에는 응답 내용 자체를 저장하지 않고 응답의 성공 여부와 응답에 걸린 시간만 기록한다 [외부API이용지침 §제8조, 시행일 2026-02-01].
- API 키의 유효기간은 1년이다 [외부API이용지침 §제9조, 시행일 2026-02-01].
- 개발팀은 유효기간 만료 14일 전에 이용 기관에 갱신 절차를 안내한다 [외부API이용지침 §제9조, 시행일 2026-02-01].
- 이용 기관은 API 키가 노출되었거나 노출이 의심되면 즉시 개발팀에 알려야 하며 개발팀은 해당 키를 폐기하고 새 키를 발급한다 [외부API이용지침 §제9조, 시행일 2026-02-01].
- 이용 기관은 API 키를 소스코드나 공개된 저장소에 두어서는 아니 된다 [외부API이용지침 §제9조, 시행일 2026-02-01].
- 개발팀은 오류 신고를 받으면 2영업일 이내에 원인과 조치 결과를 해당 기관에 회신한다 [외부API이용지침 §제10조, 시행일 2026-02-01].
- 승인이 취소된 기관은 취소일부터 6개월이 지나기 전에는 새로 이용을 신청할 수 없다 [외부API이용지침 §제11조, 시행일 2026-02-01].

## 이력
- 2026-02-01 개정 전에는 시세 조회 API의 호출 한도가 기관당 분당 600회였다 [외부API이용지침 §제6조, 시행일 2025-02-01].
