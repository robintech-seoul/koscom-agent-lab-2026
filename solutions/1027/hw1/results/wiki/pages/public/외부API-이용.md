# 외부 API 이용

## 신청과 키 발급
- 개발팀은 이용 신청서를 접수한 날부터 5영업일 이내에 심사하여 승인 여부를 통보한다 [외부API이용지침 §제3조, 2026-02-01].
- 승인된 이용 기관에는 시험 환경용 API 키를 먼저 발급하고 시험을 마친 후 운영 환경용 API 키를 발급한다 [외부API이용지침 §제3조, 2026-02-01].
- API 키의 유효기간은 1년이며 개발팀은 만료 14일 전에 갱신 절차를 안내한다 [외부API이용지침 §제9조, 2026-02-01].
- API 키 관리는 「정보보호규정」 제14조에 따른다 [외부API이용지침 §제9조, 2026-02-01].
- 이용 기관은 API 키를 소스코드나 공개된 저장소에 두어서는 아니 된다 [외부API이용지침 §제9조, 2026-02-01].

## 이용 범위와 호출 한도
- 이용 기관은 승인받은 범위의 API만 이용할 수 있고 받은 정보를 제3자에게 재판매하거나 무단으로 제공하여서는 아니 된다 [외부API이용지침 §제4조, 2026-02-01].
- 시세 조회 API의 호출 한도는 기관당 분당 300회이다 [외부API이용지침 §제6조, 2026-02-01].
- 호출 한도를 초과한 기관에 대해서는 10분간 호출을 차단한다 [외부API이용지침 §제6조, 2026-02-01].
- 시험 환경의 호출은 이용 기관당 하루 10,000회를 넘을 수 없다 [외부API이용지침 §제5조, 2026-02-01].

## 기록, 점검, 장애
- 호출 기록은 6개월간 보관하며 응답 내용 자체는 저장하지 않는다 [외부API이용지침 §제8조, 2026-02-01].
- 회사는 정기 점검을 하려는 경우 점검 예정일 3영업일 전까지 이용 기관에 알린다 [외부API이용지침 §제7조, 2026-02-01].
- 개발팀은 오류 신고를 받으면 2영업일 이내에 원인과 조치 결과를 해당 기관에 회신한다 [외부API이용지침 §제10조, 2026-02-01].
- 이용 기관은 호출 실패 시 일정한 간격을 두고 재시도하도록 시스템을 구성하여야 한다 [외부API이용지침 §제14조, 2026-02-01].

## 이력
- 2025-02-01 시행 판에서는 기관당 분당 호출 한도가 600회였다 [외부API이용지침 §제6조, 2025-02-01].
